## 一、先读这一节：证据怎么分级

这张表的每一行结论后面都要跟一个证据。证据按强度分三级，**强度弱的不能冒充强度强的**：

| 级别 | 是什么 | 为什么强 / 弱 |
| --- | --- | --- |
| **L1 可复跑脚本** | `node _ac_test.js` 这类脚本，一条条断言打勾，末尾报「通过 N 项，失败 0 项」 | 最强。别人拿到脚本能重跑，不依赖我嘴说 |
| **L2 线上实测** | curl 拿到 HTTP 状态码 + 响应体存成文件 | 强。不依赖本机，是公网上的事实 |
| **L3 人工点验** | 人眼看页面、截图 | 弱。只对那一次、那台机器成立，事后无法复核 |

**结论只有这五种**，不许含糊：

| 结论 | 意思 |
| --- | --- |
| `PASS` | 证据足够，标准里说的每一句都当场验证过 |
| `PASS(部分)` | 主要部分过了，但有一条子条件只能靠人眼 / 没验到，已写明 |
| `待人工` | 脚本测不了，必须真人点、真浏览器开 |
| `不适用` | PRD 自己改过口径，这条已经作废（附出处行号） |
| `FAIL` | 没通过，或者根本没执行 |
