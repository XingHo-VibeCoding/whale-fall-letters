## 0. 摘要

1. **给谁用**：只有一个人——我自己。没有登录、注册、多用户概念，打开网页看到的就是我的书单。
2. **解决什么问题**：想读的书散在各个 App 里凑不成一张单子；读完了没留下痕迹；阅读数据不属于自己。
3. **本期做什么**：三个功能——书单管理、阅读进度、读书笔记。
4. **做到什么程度**：能在浏览器里添加一本书、切换它的阅读状态、记录读到哪一页、为它写笔记，并且关掉浏览器再打开，数据还在。
5. **不做什么**：不提供任何书籍正文、不做阅读器、不做社交、不做统计（统计列入计划后续）。

**一句话**：一个只属于我自己的阅读记录本。

## 2. 目标用户与要解决的问题

### 2.1 目标用户

**只有一个人：我自己。**

这个决定的影响很大，写清楚：

- **没有**登录、注册、找回密码
- **没有**「我的账号」概念——打开网页，看到的就是我的书单
- **没有**多用户数据隔离
- **没有**权限、分享、公开 / 私密开关

**代价要说明白**：如果别人打开这个网址，看到的会是同一份数据。本期接受这个代价——它的定位是「自己的记录本」，不是给别人用的服务。

### 2.2 要解决的三个问题

| # | 问题           | 具体表现                                               |
| - | ------------ | -------------------------------------------------- |
| 1 | **想读的书散在各处** | 同一本书可能这个 App 有、那个没有；想读的书记在备忘录、聊天记录、脑子里，凑不成一张单子     |
| 2 | **读完了没留下痕迹** | 读完就过去了，过半年只记得「好像读过」，说不出当时什么感受                      |
| 3 | **数据不属于自己**  | 别的平台把阅读记录当成它的资产——默认公开、不给导出、不给自主分析（见 research.md 5） |

### 2.3 明确不解决的问题

写清楚「不解决什么」，避免 Day 7 做到一半范围偷偷长大：

- **不解决「这本书在哪里能看」**——这是最初那个想法的残留，已被研究推翻（research.md 2.2）
- **不解决「我读得快不快、有没有达标」**——不做时长统计、不做阅读挑战、不做好友排行
- **不解决「别人怎么看这本书」**——不做评分聚合、不做书评、不做推荐

## 3. MVP 必须包含的三个功能

每个功能按统一的四段写：**用户动作 → 可观察结果 → 边界 → 异常处理**。

---

### 3.1 书单管理

#### 用户动作

1. 在书单页点「添加书籍」
2. 在弹窗里填书名（必填），以及作者、封面网址、总页数（选填）
3. 点「保存」
4. 在列表里点某本书，进入它的详情页
5. 在详情页切换状态：想读 / 在读 / 已读
6. 回到书单页，用状态筛选查看：全部 / 想读 / 在读 / 已读
7. 在详情页点「编辑」修改这本书的信息
8. 在详情页点「删除」，在确认提示里确认后移除这本书

#### 可观察结果

- 保存后**不需要刷新页面**，这本书立刻出现在书单列表里
- 新书的默认状态是「想读」
- 列表每本书显示：封面（没有则显示书名首字）、书名、作者、当前状态
- 切换状态后，列表里这本书的标签**立刻**变成新状态；筛到「已读」时它出现在结果里
- 删除一本书时**先弹一次确认**，提示里写明会连带删除几条笔记；确认后它从列表消失，**并且这本书的笔记一并消失**
- 刷新页面后，以上所有改动仍然在

#### 边界

- 书名为空：**不允许保存**
- 书名前后带空格：保存时自动去掉
- 总页数填 0 或负数：**不允许保存**，提示「总页数要大于 0」
- 允许重复添加同一本书（不做去重——同名不同版本的书很常见）
- 封面网址留空：显示书名首字
- 封面网址填了但图加载不出来：回退显示书名首字，**不显示破图**
- 删除书籍：**必须先确认一次**，并在提示里写明会连带删除几条笔记——删书的影响比删笔记更大，不能点一下就没了

#### 异常处理

- 数据读取失败：页面**不白屏**，显示一句「数据读取失败，请刷新重试」

---

### 3.2 阅读进度

#### 用户动作

1. 进入一本书的详情页
2. 在「进度」区域填：当前读到第几页
3. 添加或编辑这本书时，填总页数
4. 状态为「在读」时，进度可以随时更新

#### 可观察结果

- 填了总页数时，详情页显示「第 120 / 320 页」和百分比「38%」
- 没填总页数时，只显示「第 120 页」，**不显示百分比**（不瞎猜）
- 把状态改为「已读」时，进度自动变成「读完」，完成日期记为今天
- 书单列表里，状态为「在读」的书显示当前进度

#### 边界

- 填了总页数的情况下，当前页数大于总页数：**不允许保存**，提示「当前页数不能超过总页数」
- 当前页数为负数或不是数字：不允许保存
- 没填总页数但填了当前页数：允许，只是不显示百分比
- 状态为「想读」的书：**不显示进度区域**（还没开始读，进度没有意义）
- **允许把进度改小**（记错了要能纠正），不设「只能往前」的限制

#### 异常处理

- 一本书的总页数被改成比当前页数还小：提示冲突，让用户改其中一个，**不静默改数据**

---

### 3.3 读书笔记

#### 用户动作

1. 进入书籍详情页
2. 在「笔记」区域点「写笔记」
3. 填笔记正文（必填），可选填页码
4. 保存
5. 在已有笔记上点「编辑」，修改正文或页码后保存，**更新原来那条**（不是新增一条）

#### 可观察结果

- 保存后笔记立刻出现在这本书的笔记列表里，**最新的在最上面**
- 每条笔记显示：正文、页码（如果填了）、创建时间
- 笔记只出现在**所属那本书**的详情页，不会串到别的书
- 编辑一条已有笔记并保存后，**那条笔记的内容被更新**，列表里**不会多出一条**
- 删除一本书时，它的笔记一并删除
- 刷新页面后笔记还在

#### 边界

- 笔记正文为空：不允许保存
- 正文只有空格：视为空，不允许保存
- 笔记条数不限
- 单条笔记长度不设上限（自己用，不需要防灌水）
- 一条笔记只属于一本书，**不做**跨书标签或全局笔记池

#### 异常处理

- 打开编辑后取消：原内容**保持不变**（不能因为点开编辑器就把内容弄丢）
- 删除笔记：**必须先确认一次**，避免误删

## 4. 页面与数据字段

### 4.1 页面清单

三个视图：

| #      | 视图          | 用户怎么到达            | 必须包含的元素                                                                                 |
| ------ | ----------- | ----------------- | --------------------------------------------------------------------------------------- |
| **P1** | 书单页（首页）     | 打开网站              | 状态筛选（全部 / 想读 / 在读 / 已读）、书籍卡片列表、每张卡片显示封面或书名首字 + 书名 + 作者 + 状态 +（在读时）进度、「添加书籍」按钮           |
| **P2** | 书籍详情页       | 在列表点某本书           | 书名、作者、封面、状态切换（三态）、进度录入区（状态为「想读」时不显示）、笔记列表、「写笔记」按钮、每条笔记的「编辑」「删除」按钮、本书的「编辑」「删除」按钮、返回列表的入口 |
| **P3** | 添加 / 编辑书籍弹窗 | 点「添加书籍」，或详情页点「编辑」 | 书名（必填）、作者、封面网址、总页数、保存、取消                                                                |

**页面跳转关系**：

```
书单页 P1 ──点某本书──▶ 详情页 P2
   │                       │
   └──点「添加书籍」──▶ 弹窗 P3 ◀──点「编辑」┘
```

**空状态**，分两种，别混：

- **一本书都没有**：显示一句提示 + 一个「添加第一本书」按钮，而不是一片空白。
- **有书、但当前筛选档下没有**（Day 7 补充）：显示一句「没有「XX」的书」+ 一个「看全部」按钮。原文只规定了上一种；实际用起来，点了筛选看到空白页容易被当成页面坏了 —— 所以这里补上出口。

  > 这一条是**对上面那条的细化**，没有单独开验收标准（AC 仍是 23 条）。理由是它不引入新的用户动作，只是把一片空白换成一句话。


### 4.2 数据字段 · 书籍 Book

| 字段            | 类型  | 必填 | 说明                                                 |
| ------------- | --- | -- | -------------------------------------------------- |
| `id`          | 字符串 | 系统 | 唯一标识，创建时自动生成                                       |
| `title`       | 字符串 | ★  | 书名，保存前自动去掉首尾空格                                     |
| `author`      | 字符串 |    | 作者                                                 |
| `coverUrl`    | 字符串 |    | 封面图网址；空 → 显示书名首字；加载失败 → 回退首字                       |
| `status`      | 枚举  | ★  | `want` 想读 / `reading` 在读 / `finished` 已读；默认 `want` |
| `totalPages`  | 整数  |    | 总页数，须大于 0                                          |
| `currentPage` | 整数  |    | 当前页数，须不小于 0；填了总页数时不得超过它                            |
| `startedAt`   | 日期  | 系统 | 状态**首次**变为「在读」时自动写入                                |
| `finishedAt`  | 日期  | 系统 | 状态变为「已读」时自动写入                                      |
| `createdAt`   | 日期  | 系统 | 创建时间                                               |
| `updatedAt`   | 日期  | 系统 | 最后修改时间                                             |

**派生值**（不存字段，页面实时算）：

- 进度百分比 = `currentPage ÷ totalPages`，四舍五入到整数
- 前提：两者都存在，且 `totalPages > 0`

**关于「必填」列里的「系统」**：表示该字段由程序自动生成和维护，**页面不显示、用户填不了**，所以不写单独的验收标准。它们的作用是支撑页面上能看到的东西——例如 `finishedAt` 支撑 AC-14 里的「完成日期自动记为今天」。

### 4.3 数据字段 · 笔记 Note

| 字段          | 类型  | 必填 | 说明               |
| ----------- | --- | -- | ---------------- |
| `id`        | 字符串 | 系统 | 唯一标识             |
| `bookId`    | 字符串 | ★  | 所属书籍的 id         |
| `content`   | 字符串 | ★  | 笔记正文，去掉首尾空格后不能为空 |
| `page`      | 整数  |    | 关联页码，选填          |
| `createdAt` | 日期  | 系统 | 创建时间，列表按它倒序排列    |
| `updatedAt` | 日期  | 系统 | 最后修改时间           |

### 4.4 本文档不涉及的部分

以下决定留给 Day 5 技术设计：

- 数据存在哪里（浏览器本地 / 数据库）
- 页面用什么渲染
- 用户填的封面网址如何加载、失败时如何回退
- 删除书籍时，笔记在数据层是级联删除还是标记删除

> 最后一条虽然是实现选择，但**对用户的承诺已经写在第 3.1 节**：删书时笔记一并消失。具体怎么做，Day 5 决定。

### 6.1 功能验收

**书单管理**

| #     | 场景                               | 通过标准                                                |
| ----- | -------------------------------- | --------------------------------------------------- |
| AC-1  | 我在书单页点「添加书籍」，填书名「三体」、作者「刘慈欣」，点保存 | 弹窗关闭，列表里立刻出现「三体」，状态为「想读」，**不需要刷新页面**                |
| AC-2  | 我在弹窗里不填书名直接点保存                   | 看到提示，弹窗**不关闭**，**且没有**产生一条空书名的记录                    |
| AC-3  | 我添加一本书时填了一个能正常打开的封面图片网址          | 列表和详情页都显示这张图                                        |
| AC-4  | 我添加一本书时**没有**填封面网址               | 显示书名第一个字占位，**不是**一个破图图标                             |
| AC-5  | 我填了一个打不开的封面网址                    | 回退显示书名第一个字，**不是**破图                                 |
| AC-6  | 我在详情页把一本书从「想读」改成「在读」             | 详情页和列表页的标签都立刻变成「在读」                                 |
| AC-7  | 我在书单页依次点「想读」「在读」「已读」「全部」四个筛选     | 前三档**只显示**对应状态的书；「全部」档显示所有书                         |

## 附：术语

| 术语             | 白话解释                                                  |
| -------------- | ----------------------------------------------------- |
| **MVP**        | Minimum Viable Product，最小可用版本——功能最少、但能真正用起来的那一版       |
| **PRD**        | Product Requirements Document，产品需求文档——把「要做什么」写成能验收的规格 |
| **验收标准 / AC**  | Acceptance Criteria，一条条可以回答「是 / 否」的检查项                |
| **弹窗 / Modal** | 在当前页面上浮出的小窗口，操作完就关，不离开当前页面                            |
| **空状态**        | 还没有任何数据时页面显示的样子（比如「还没有书，点这里添加第一本」），而不是一片空白            |
| **派生值**        | 不单独存储、需要时现算的值。这里是进度百分比——存了反而容易和页数对不上                  |
| **级联删除**       | 删掉主记录时连带删掉从属于它的记录（这里是删书时连带删笔记）                        |
| **DNF**        | Did Not Finish，弃读。「没读完的书」也是一条值得记录的信息                  |
