### 这张表必须说清的三件事（不粉饰）

1. **三行结论是映射来的，不是他说的。** 原始对话只有 `是 / 是 / ok / 在 / 有 / 没有` 六个字。截图要交「同伴给出的三行结论」，严格讲这一条**打了折扣**——他能证明的是「这 6 步都过了」，不是我列的那三个词他都认了。

## 四、顺利应该长什么样（用来区分「他卡住了」和「本来就这样」）

| 步骤 | 顺利的样子                                                     |
| -- | --------------------------------------------------------- |
| 1  | 深蓝紫底的书架页，顶部写着「鲸落书简」，右上角一排导航，中间有个空白提示 + 「添加第一本书」           |
| 2  | 弹出一个窗口让你填书名/作者/封面，保存后窗口关掉，卡片**立刻**出现在列表里，标签是「想读」          |
| 3  | 只有状态是「在读」的书才有进度输入框（**这是设计**）；笔记框在详情页下方，保存后出现在列表最上面        |
| 4  | 书和笔记**都还在**，页面还停在原来那一页（不会跳回首页）                            |
| 5  | 表格里出现 5 本书：三体 / 活着 / 人类简史 / 小王子 / 国境以南 太阳以西，下面有一行「最后更新：…」 |
| 6  | 没有红色横幅、没有白屏。**注意**：如果他中途断网了，会出现一条可读的提示 + 「重试」按钮，那不是 bug   |

**已知的正常现象，不要记成 bug**：

- 「接口数据」页只在 CloudBase 地址下能通，Pages 地址下会提示抓取失败（域名白名单），这是已知的
- 论坛 / 消息 / 登录 里的账号、帖子数据是**内存里的 mock**，刷新会清空——后端还没接这部分
- 刷新后不用重新登录，社区层的登录态本来就只在当前页有效
