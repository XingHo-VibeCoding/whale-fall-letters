## 一、书单管理（AC-1 ~ AC-10）

| 打勾 | # | 你要做什么 | 应该看到什么 |
|---|---|---|---|
| ☐ | AC-1 | 书单页点「添加书籍」，填书名「三体」、作者「刘慈欣」，保存 | 弹窗关闭，列表里**立刻**出现「三体」，状态「想读」，**不用刷新** |
| ☐ | AC-2 | 弹窗里**不填书名**直接点保存 | 有提示、**弹窗不关**、库里**没多出一条空书名记录**（可去 SQL 查 `select count(*) from books where title=''`）|
| ☐ | AC-3 | 添加时填一个**能打开的**封面图片网址 | 列表和详情页都显示这张图 |
| ☐ | AC-4 | 添加时**不填**封面网址 | 显示书名**第一个字**占位，不是破图图标 |
| ☐ | AC-5 | 填一个**打不开的**封面网址（比如 `https://xxx.invalid/a.jpg`）| 回退成书名第一个字，不是破图 |
| ☐ | AC-6 | 详情页把一本书从「想读」改成「在读」 | 详情页和列表页标签**都**立刻变「在读」 |
| ☐ | AC-7 | 依次点「想读」「在读」「已读」「全部」四个筛选 | 前三档**只显示**对应状态；「全部」显示所有 |
| ☐ | AC-8 | 详情页点「编辑」，把作者从空改成「刘慈欣」保存 | 弹窗关闭，详情页和列表页作者**都**变成「刘慈欣」 |
| ☐ | AC-9 | 一本都没有时打开书单页 | 有提示 + 「添加第一本书」按钮，**不是一片空白** |
| ☐ | AC-10 | 详情页点「删除」→ 先点「取消」→ 再点「删除」并确认 | **先弹确认**；取消后书还在；确认后书从列表消失，它的笔记也不再出现在任何页面 |

> **AC-10 补充**：Day 23 起底层是**软删除**（数据行还在，`is_deleted = true`）。所以"消失"指的是界面上看不到，不是数据被删。删错了可以用 SQL 把 `is_deleted` 改回 `false` 找回来。

| 打勾 | # | 你要做什么 | 应该看到什么 |

| ☐ | AC-15 | 某本书详情页写一条笔记并保存 | 笔记**立刻**出现在这本书笔记列表的**最上方** |

## 五、这份清单之外，还有三条要单独看

PRD 没写，但真上线前必须过：

| 打勾 | 检查项 | 怎么验 |
|---|---|---|
| ☐ | **手机宽度** | 浏览器缩到 **390px** 宽（F12 → 设备模拟 → iPhone），看首页/论坛/我的三页：有没有横向溢出、按钮有没有挤成一团 |
| ☐ | **键盘可操作** | **只用 Tab / Enter / Space** 走一遍：加书 → 切筛选 → 进论坛 → 搜索 → 发帖。看焦点框看不看得见、能不能走完全程 |
| ☐ | **换账号看陌生数据** | A 发一篇帖 + 一条评论 + 一条私信 → 退出 → B 登录 → **能看到 A 的帖子和评论，但看不到 A 的私信** |

最后一条最重要 —— 它是"公开社区"和"单机版"的分界线。
